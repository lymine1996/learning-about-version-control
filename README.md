# learning-about-version-control
Learning about Version Control

Solving merge conflicts takes conscious effort, but I can do it!

What I like most about version control is the safety net it provides—being able to experiment freely on branches, track exact diffs over time, and revert a bad change without losing good work. 

What I find most frustrating is untangling messy merge conflicts or rebasing history after diverging too far, where a single wrong command can leave the working tree or commit graph in a confusing state.
